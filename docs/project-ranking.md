# Project Ranking & Flagship Selection

The portfolio prioritizes honest, public engineering work over inflated project count.

## Flagship / full case studies

1. **PharmaStock — Medicine Stock Management & Analytics Portal**
   - React inventory product with batch tracking, expiry and low-stock intelligence, role-based UI, analytics, and a service layer prepared for an Express/Mongo backend.
   - Status: academic project; frontend is runnable on demo data and the backend boundary is documented.
2. **Command Argument Passing System**
   - C/Linux systems work demonstrating `fork`, `execvp`, `waitpid`, argument transfer, signals, and process inspection.
   - Status: source publication is in progress; public repository scope is labeled honestly.

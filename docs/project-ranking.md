# Project Ranking & Flagship Selection

The portfolio prioritizes honest, public engineering work over inflated project count.

## Flagship / full case studies

1. **ForgeSense Industrial Intelligence**
   - Spring Boot + FastAPI industrial operations platform with synthetic telemetry, digital-twin state, eventing adapters, WebSockets, observability, and experimental ML assessments.
   - Status: portfolio/academic project with explicit development and synthetic-data limits.
2. **LogInsight Analyzer**
   - Full-stack algorithm laboratory with executable string, dynamic-programming, graph/flow, approximation, randomized, and parallel modules plus trace playback and tests.
   - Status: academic/portfolio project; runtime data is in memory.
3. **PharmaStock — Medicine Stock Management & Analytics Portal**
   - React inventory product with batch tracking, expiry and low-stock intelligence, role-based UI, analytics, and a service layer prepared for an Express/Mongo backend.
   - Status: academic project; frontend is runnable on demo data and the backend boundary is documented.
4. **Command Argument Passing System**
   - C/Linux project abstract describing a planned `fork`/`exec`/`wait` argument-passing design.
   - Status: documentation-only; implementation source is not currently published.
